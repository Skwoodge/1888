# 1888 Americano Society — Website Refocus Plan

> **Goal:** Refocus the website from "rodeo group" to "Mexican American heritage and veterans" so people stop being confused. Add sponsorship tiers. Meet the July 4th deadline.

**Problem:** People think this is a rodeo group. The website's hero says "1888 Americano Society" with a rodeo image and the tagline "Honoring America, Preserving Heritage, Strengthening Community" — but nothing immediately communicates that this is about Mexican American veterans and heritage in Prescott/Yavapai County. The email from the friend and the feedback from potential volunteers confirm the confusion.

**Current state:** React + Vite + Tailwind site live at 1888americanosociety.org. GitHub → Cloudflare Pages auto-deploy. History and Juan Leivas are separate pages. Sponsorship tiers on Events page are outdated ($100/$250/$500).

**Timeline:** June 21 → July 4 (13 days). Must be done before parade.

**Approach:** Work on localhost (`npm run dev`). When ready, batch push to GitHub for auto-deploy. No live changes until all updates are complete.
